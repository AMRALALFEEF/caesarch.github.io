شركة دقة المعايرة للاستشارات الهندسية
نسخة الموقع: الهوية البيضاء والزرقاء + مشاريع الشركة

طريقة الرفع إلى GitHub:
1) ارفع index.html ومجلد assets كاملًا إلى المستودع.
2) تأكد أن index.html في جذر المستودع.
3) GitHub Pages -> Deploy from a branch -> main -> /(root).
4) احفظ وانتظر اكتمال النشر.
