الموقع يميز بوضوح بين «تصور سكني» و«مرجع بصري» ولا يقدّم الصور على أنها مشاريع منفذة للشركة. بعض الصور محمّلة من مصادر عامة على الويب وتُستخدم بصفتها مراجع بصرية. قبل النشر التجاري النهائي يُفضّل استبدالها بصور مشاريع الشركة أو صور مرخصة للاستخدام التجاري.

## رفعه على GitHub Pages
1. فك الضغط.
2. افتح GitHub وأنشئ Repository جديدًا.
3. ارفع **كل الملفات الموجودة داخل مجلد `daqah_site`** إلى جذر المستودع.
4. من Settings > Pages اختر Deploy from a branch.
5. اختر Branch: `main` وFolder: `/ (root)` ثم Save.
6. بعد دقائق سيظهر رابط الموقع.

مهم: لا ترفع مجلد `daqah_site` كطبقة إضافية داخل المستودع إذا أردت أن يعمل `index.html` مباشرة من الجذر؛ ارفع محتويات المجلد نفسها.
